# ApkVault — 테스터 12명 모집·비공개 테스트 안내

2023년 11월 이후 만든 **개인** 개발자 계정은 정식 출시 전에
**테스터 12명 이상이 14일 연속으로 참여한 비공개 테스트**를 마쳐야 "프로덕션 액세스"를 신청할 수 있습니다.

## 1. 진행 순서

1. **테스터 Gmail 모으기** (아래 3번 모집 글 사용). 중간에 빠지는 사람을 생각해 **15~20명** 모으세요.
2. Play Console → 테스트 및 출시 → 테스트 → **비공개 테스트** → 트랙 만들기 (예: "closed-beta")
3. **테스터** 탭 → 이메일 목록 만들기 → 모은 Gmail 붙여넣기 → 저장
4. **새 버전 만들기** → `ApkVault-release` 안의 `app-release.aab` 업로드 → 출시 노트 입력 → 검토 후 출시
   (첫 검토는 며칠 걸릴 수 있음)
5. 검토가 끝나면 **테스터 탭의 "웹에서 참여" 링크**를 복사해 테스터에게 보냄 (아래 4번 안내 글)
6. 유료 앱이라 테스터도 구매가 필요할 수 있음 → **프로모션 코드**를 1명에 1개씩 보냄 (아래 2번)
7. 테스터 12명 이상이 **참여한 상태로 14일** 지나면 → 대시보드 → **프로덕션 액세스 신청**
   (테스트 중 받은 의견과 고친 점을 묻는 설문이 나오므로 메모해 두기)

> 테스터가 중간에 "테스트 그만두기"를 누르면 그 사람은 빠집니다. 14일 동안 앱을 지우지 말고 참여를 유지해 달라고 꼭 부탁하세요.

## 2. 프로모션 코드 (테스터가 돈 내지 않게)

Play Console → 수익 창출 → **프로모션** → 프로모션 만들기
- 종류: **앱** (ApkVault 자체를 무료로 받게 하는 코드)
- 개수: 테스터 수만큼 (분기마다 최대 500개)
- 기간: 테스트 기간 + 여유 (예: 30일)
- 만든 코드를 내려받아 **한 사람에게 하나씩** 보냄. 받은 사람은 Play 스토어 → 프로필 → 결제 및 구독 → **코드 사용**

> 프로모션 코드는 앱이 Play 스토어에 한 번 출시(테스트 트랙 포함)된 뒤에 만들 수 있습니다.
> 테스트 트랙에서 코드가 안 먹히면, 테스터가 구매한 뒤 금액을 따로 돌려주는 방법도 있습니다. 무료로 바꿨다가 다시 유료로 되돌리는 건 불가능하니 하지 마세요.

## 3. 모집 글 (카카오톡·단톡방·커뮤니티용)

```
[테스터 모집] 광고 없는 APK 추출 앱 'ApkVault' 비공개 테스트에 참여해 주실 분을 찾습니다 🙏

📱 어떤 앱?
휴대폰에 설치된 앱을 APK 파일로 꺼내 백업·공유하는 앱이에요.
광고·추적 없고 인터넷 권한도 없어요. 큰 앱은 30MB씩 나눠 저장해서
AI 채팅(Claude 등)이나 메일에도 올릴 수 있어요.

✅ 참여 조건
• 안드로이드 휴대폰 + Gmail(구글 계정)
• 14일 동안 앱을 지우지 말고 테스트 참여 상태 유지 (매일 쓰실 필요는 없어요)

🎁 참여하시면
• 유료 앱을 무료로 받는 코드를 드려요 (출시 후에도 계속 사용)

👉 참여 방법
이 글에 답장으로 Gmail 주소만 알려 주세요.
며칠 안에 참여 링크와 코드를 보내 드릴게요.
```

```
1) 아래 링크를 휴대폰에서 열고, 알려 주신 Gmail 계정으로 로그인한 상태에서
   "테스터 되기"를 눌러 주세요.
   👉 [Play Console 테스터 탭의 '웹에서 참여' 링크]

2) Play 스토어 → 오른쪽 위 프로필 → 결제 및 구독 → "코드 사용"에
   아래 코드를 넣어 주세요. (무료로 받아져요)
   🎟 코드: [프로모션 코드]

3) 링크 페이지의 "Google Play에서 다운로드"를 눌러 설치하면 끝!

⚠ 꼭 지켜 주세요
• 14일 동안 앱을 지우거나 "테스트 그만두기"를 누르지 말아 주세요.
• 불편한 점이나 오류가 있으면 편하게 알려 주세요. 출시 전에 고칠게요.
```
